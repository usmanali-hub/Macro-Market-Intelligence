# Macro Market Intelligence — Visualizations

These charts are generated by the real macroeconomic data pipeline and are published by GitHub Actions after the analysis workflow runs.

## Available charts

- Interest-rate trends
- Inflation and unemployment context
- Historical indicator correlations
- Heuristic macro-regime frequency

The charts are generated from public economic data. Derived metrics and heuristic regimes are analytical constructs, not official releases or investment signals.
