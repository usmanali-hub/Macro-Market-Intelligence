# Macro Market Intelligence

## Turning economic indicators into market context

A reproducible macroeconomic analytics project that transforms public economic indicators into **structured, decision-oriented market insights** using Python, SQL, data preparation, derived metrics, and visualization.

The project focuses on the analytical layer between raw economic releases and an interpretable market narrative: **what changed, how indicators interact, and which relationships deserve further investigation.**

## Business Questions

- How are U.S. interest rates evolving over time?
- How do inflation and unemployment move relative to monetary policy conditions?
- What does the spread between the 10-year Treasury yield and the federal funds rate suggest about the rate environment?
- How quickly are macro conditions changing over a three-month window?
- Which macro indicators show meaningful historical relationships?
- How can multiple indicators be combined into a consistent analytical view?

## Indicators

The project works with public U.S. macroeconomic series including:

- Federal funds rate
- Consumer price index
- Unemployment rate
- GDP
- 10-year Treasury yield

Derived measures include year-over-year growth rates, rate changes, and a yield-curve proxy based on the 10-year Treasury yield minus the federal funds rate.

## What This Project Demonstrates

This project demonstrates practical Data Analyst capabilities in **economic data analysis, data cleaning, time-series alignment, feature engineering, exploratory analysis, SQL, visualization, and evidence-based interpretation**.

It is particularly useful for demonstrating the ability to work with datasets where the analytical challenge is not just calculating a number, but connecting several indicators into a coherent business or market context.

## Reproducibility

Install the dependencies and run the pipeline from the repository root:

```bash
pip install -r requirements.txt
python src/download_data.py
python src/clean_data.py
python src/analyze_macro.py
```

Generated data and charts can be recreated locally rather than being treated as static portfolio artifacts.

## Data Integrity Note

The project uses public economic data and is intended for analytical demonstration and research. Correlation does not establish causation, and the derived indicators should not be interpreted as investment advice or standalone trading signals.
