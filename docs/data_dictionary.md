# Data Dictionary

| Field | Meaning | Analytical use |
|---|---|---|
| date | Observation date | Time alignment and trend analysis |
| fed_funds | Federal funds rate | Monetary-policy conditions |
| cpi | Consumer price index | Inflation measurement |
| unemployment | U.S. unemployment rate | Labor-market conditions |
| gdp | Gross domestic product | Economic growth |
| treasury_10y | 10-year Treasury yield | Long-term rate expectations |
| cpi_yoy_pct | Year-over-year CPI change | Inflation momentum |
| gdp_yoy_pct | Year-over-year GDP change | Growth momentum |
| yield_curve_proxy | 10Y Treasury minus fed funds | Rate-curve context |
| rate_change_3m | Three-month fed-funds change | Policy direction |

## Interpretation rules

- Indicators are aligned to a common analysis frequency before comparison.
- Derived measures are analytical features, not official economic releases.
- Correlation is descriptive and does not establish causation.
- Any regime classification in this project is heuristic and should be treated as an analytical framework rather than a forecasting model.
