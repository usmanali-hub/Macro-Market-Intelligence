# Recruiter / Interview Walkthrough

## 30-second explanation

“I built a reproducible macroeconomic analytics pipeline that pulls public economic indicators, aligns different frequencies, engineers momentum and standardized features, classifies heuristic macro regimes, and turns the results into SQL queries and decision-oriented reporting.”

## What to show first

1. `src/analyze_macro.py` — analytical logic.
2. `sql/analysis_queries.sql` — business questions in SQL.
3. `docs/data_dictionary.md` — data discipline.
4. `reports/executive_dashboard.md` — communication layer.
5. `.github/workflows/quality.yml` — reproducibility and quality.

## What this proves

- Can work with imperfect time-series inputs.
- Can engineer interpretable analytical features.
- Can separate descriptive analysis from predictive claims.
- Can communicate uncertainty and analytical limitations.
- Can package analysis as a reproducible repository.
